Cuidar é uma forma de amar

Aprenda sobre HTML Semântico

O que é HTML semântico?

HTML semântico é uma forma de construir páginas utilizando elementos que possuem significado sobre o conteúdo que organizam. Em vez de usar apenas elementos genéricos, como <div>, utilizamos tags que explicam a função daquela área.

Por que utilizar tags semânticas?

Elas tornam o código mais organizado e compreensível para desenvolvedores, ajudam mecanismos de busca a entender a estrutura da página e favorecem a acessibilidade para pessoas que utilizam tecnologias assistivas.

Exemplos de elementos semânticos

  • <header>: representa o cabeçalho de uma página ou seção.
  • <main>: identifica o conteúdo principal da página.
  • <section>: organiza um conjunto de conteúdo relacionado.
  • <article>: representa um conteúdo independente ou autocontido.
  • <footer>: representa o rodapé de uma página ou seção.

Aprenda sobre CSS

O que é CSS?

CSS significa Cascading Style Sheets, ou Folhas de Estilo em Cascata. É a linguagem utilizada para definir a aparência e a apresentação visual de uma página.

Para que serve?

Com CSS podemos controlar cores, fontes, espaçamentos, tamanhos, bordas, posicionamento, animações e o comportamento visual da página em diferentes telas.

Exemplos de propriedades CSS

  • color: define a cor do texto.
  • background-color: define a cor de fundo.
  • font-size: controla o tamanho da fonte.
  • margin: controla o espaço externo de um elemento.
  • padding: controla o espaço interno de um elemento.
  • border: define bordas.

Estrutura x apresentação

O HTML define o que o conteúdo é e como ele está estruturado. O CSS define como esse conteúdo será apresentado. Separar essas responsabilidades torna o projeto mais organizado e fácil de manter.

Design Responsivo

O que é Design Responsivo?

Design responsivo é uma abordagem que permite que uma página se adapte a diferentes tamanhos e orientações de tela, como celulares, tablets, notebooks e monitores.

Por que funciona em diferentes telas?

As pessoas acessam sites por dispositivos muito diferentes. Uma interface responsiva melhora a leitura, a navegação e a experiência do usuário independentemente do tamanho da tela.

O que são componentes responsivos?

São elementos da interface que conseguem ajustar tamanho, posição, espaçamento ou disposição conforme o espaço disponível. Cards, menus, imagens e grids podem ser responsivos.

O que são breakpoints?

Breakpoints são pontos definidos no CSS nos quais o layout pode mudar para se adaptar a determinada largura de tela. Eles são normalmente utilizados com media queries.
